【GitHubへの登録】
1. このZIPをiPhoneの「ファイル」アプリで展開します。
2. GitHubで assy9784/wishlist を開きます。
3. Add file → Upload files を選びます。
4. 展開したフォルダの中の index.html / manifest.webmanifest / sw.js / アイコン画像をすべてアップロードします。
5. Commit changes を押します。

【GitHub Pagesの公開】
リポジトリの Settings → Pages → Build and deployment で
Deploy from a branch / main / /(root) を選んで Save します。
公開後のURLは https://assy9784.github.io/wishlist/ です。

【iPhoneに追加】
公開URLをSafariで開き、共有ボタン → ホーム画面に追加。

【データについて】
登録内容はこのiPhoneのブラウザ内に保存されます。定期的に「バックアップを書き出す」を使ってください。
